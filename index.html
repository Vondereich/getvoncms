Editorial workflow

From a first draft to a published story.

Writers prepare the story. Authorized reviewers decide when it goes live.

  1. 01

    Write

    Prepare the article with text, images, and publishing details.

  2. 02

    Submit

    Send the draft for review without giving writers publishing access.

  3. 03

    Review

    Return it for changes, schedule it, or approve it for publication.

  4. 04

    Publish

    The story goes live on your website for readers to find.

Writers can withdraw and revise drafts. Publishing permissions stay with authorized staff.

Get started

A home for your next publication.

Run VonCMS on compatible PHP and MySQL hosting. No Node.js runtime or separate frontend server required.

  1. Download VonCMS.

    Choose the ready-to-install package, named Deploy ZIP in each release.

  2. Upload it to your hosting.

    Extract the package into your website directory and create a database.

  3. Finish setup in your browser.

    Open the installer, enter the setup key from your hosting files, then connect the database and create your admin account.

Before you start

A few practical answers.

Need hosting or installation details? Start with the docs.

Is VonCMS meant to replace WordPress?

Not for everyone. WordPress has a mature ecosystem and serves many kinds of websites. VonCMS is a smaller, publishing-focused alternative for people who want a self-hosted editorial workflow, bundled themes, and direct access to their source and data. Choose the CMS that fits your publication.

Do I need Node.js to run VonCMS?

No. The Deploy ZIP includes built frontend assets and runs on PHP and MySQL hosting. Node.js and npm are only needed if you develop from source or create a custom build.

Is VonCMS free and open source?

Yes. VonCMS is released under GPL-3.0-only. The software is free; your hosting, domain, and any optional paid services are separate costs. If you distribute modified copies, follow the license requirements.

Can I bring content from WordPress?

VonCMS includes a WordPress XML importer. Test an import on a staging site first, and check articles, media, categories, and links before changing your live website. WordPress themes and plugins are not interchangeable with VonCMS.
