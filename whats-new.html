VonCMS v1.27.0 "OverDrive"

OverDrive opens the v1.27 series with a structured Writer review workflow, shared AI writing, crawlable public pagination, stronger role boundaries, and consent-aware analytics.

Highlights

  • Added Writer draft submission and staff review workflow.
  • Added reviewer Review queue and Writer Submitted tab.
  • Writers can submit, withdraw, and revise drafts without gaining publishing authority.
  • Moderators, Admins, and Root can return, schedule, or publish submitted posts.
  • Added shared AI writing for authorized staff without exposing the central API key.
  • Refreshed supported Gemini models and strengthened HTML-preserving AI review.
  • Added crawlable, base-path-safe ?page=N pagination across all six bundled themes.
  • Improved no-JavaScript pagination, metadata, search, category, RSS, sitemap, and public rendering consistency.
  • Added consent-aware Native Analytics and Google Analytics handling.
  • Removed duplicate article view counting.

Editor And Admin

  • Improved editor spacing and toolbar contrast.
  • Added consistent title, excerpt, and keyword limits across frontend and server APIs.
  • Fixed Archived workflow labels and saved-state feedback.
  • Fixed Page navigation checkbox persistence.
  • Added clearer post-loading and failure messages.
  • Strengthened account boundaries between Super Admin, appointed Admins, and lower roles.
  • Added the red Super Admin identity throughout relevant admin and profile surfaces.
  • Improved TechPress contrast, card truncation, author-name handling, and metadata layout.

Security And Reliability

  • Rejects appended path segments after PHP entry points.
  • Protects internal helper files from direct requests.
  • Strengthened POST-only enforcement for database import and logout.
  • Added stale-review conflict protection using canonical row locking and 409 responses.
  • Added bounded AI quotas, controlled provider failures, and safe model fallback behavior.
  • Added bounded SMTP delivery deadlines and strict response validation.
  • Split public bootstrap responsibilities into guarded helpers while preserving root, subdomain, and subfolder behavior.
  • Updated OpenRouter, TipTap, Multer, Express Rate Limit, Lucide React, PostCSS, type packages, and related dependencies.

Upgrade Notes

  1. Back up the website files and database.
  2. Upload the v1.27.0 Deploy ZIP using the normal VonCMS update process.
  3. Sign in as the primary administrator.
  4. If integrity checks report outdated rules, run System Tools > Repair `.htaccess`.
  5. Nginx deployments must apply the equivalent rules documented in docs/VPS.md.
  6. v1.27.0 itself introduces no new database migration.
  7. Sites that have not completed the earlier v1.26.11 schema upgrade must run Settings > Tools > Repair Database once.
  8. Verify the homepage, one article, one page, search, pagination, and the admin dashboard after updating.

Release Verification

  • TypeScript typecheck passed.
  • PHP lint passed across 108 PHP files.
  • Prettier formatting passed.
  • Production build passed.
  • Integration tests passed before and after packaging.
  • npm audit --audit-level=high reported zero vulnerabilities.
  • Deploy and Source ZIP contents were verified.
