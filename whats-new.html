VonCMS v1.28.1 - The BluePrint

Release date: 6 November 2026

This update adds optional publishing tools, clearer analytics controls, safer deletion confirmations, and targeted reliability and authorization fixes.

Highlights

  • Opt-in Hybrid Analytics: Record Strict IP-window and Balanced browser-session measurements independently. Reports remain separate, with clearer collection-status guidance. Existing collection settings and history are preserved.
  • Post/Page Deletion Previews: Review selected records before single or bulk permanent deletion. Includes cancellation, duplicate-click protection, partial-failure retry, and reliable list refresh after navigation. This is not Trash, Restore, or Undo.
  • Optional News Sitemap: Enable /sitemap-news.xml through VonSEO Advanced settings. Includes publication name, language and category controls, a 48-hour publication window, and up to 1,000 articles per file. News files are linked from the existing sitemap index.
  • Measurement Hygiene: Exclude recognized crawlers and automation from new native analytics measurements without blocking public content. Concurrent Strict requests no longer record the same initial visit window twice. Counts remain estimates, not verified human visitors.
  • Authorization Corrections: Protected Post reads require successful session revalidation. Comment moderation and the Primary Admin's IndexNow controls enforce their intended role boundaries.
  • Leaner Public Reads: Cache optional author-column metadata checks, avoid unused listing requests in affected themes, and improve Related Posts candidate handling.
  • Dashboard and Documentation: Improve dark-mode selectors/tooltips, compact Recent Activity spacing, and clarify which settings are publicly visible.
  • Dependency Maintenance: Update OpenRouter SDK to 1.5.57, the TipTap family to 3.33.0, and compatible supporting dependencies.

Upgrade Notes

  • Back up application files and the database before updating.
  • No new database table or required migration is introduced when upgrading from v1.28.0.
  • Hybrid analytics and News Sitemap require explicit configuration; neither is enabled automatically.
  • Calendar and Balanced/Hybrid analytics retain their existing storage prerequisites. Older installations should follow the upgrade guide.
  • PHP 8.2 remains the minimum; PHP 8.3+ is recommended. Use a security-patched runtime.
  • Installer, bundled theme and built-in plugin labels remain 1.28.
  • News Sitemap does not guarantee Google News inclusion. Articles leaving its 48-hour window are not deleted.

Verification

  • GitHub CI passed on PHP 8.2 and 8.3.
  • TypeScript, ESLint, PHPStan Level 9, formatting, BOM, build and integration checks passed.
  • Local isolated editor and Dashboard browser tests passed.
  • npm audit reported 0 known vulnerabilities.
  • Both ZIP manifests and file contents were verified, including 261 extracted PHP syntax checks.
