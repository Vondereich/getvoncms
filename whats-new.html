VonCMS v1.28.3

Highlights

  • Personal AI Keys: Primary Admin, appointed Admin, Moderator and Writer can save an encrypted personal Gemini key. Writer/Moderator receive self-only account access.
  • Safe Key Selection: Personal keys take priority. Expired, damaged or rejected personal keys never silently fall back to the shared paid key.
  • Optional Expiry: Personal keys can expire 30 days after Save/Replace.
  • Encryption Rotation: Primary Admin rotation covers shared and personal keys. Rotation currently requires an encrypted shared key.
  • Repair Notifications: Database readiness checks now include personal AI key storage.

Improvements and Fixes

  • Fixed slug routing boundaries.
  • Improved site-name/title encoding across metadata, structured data and RSS.
  • Aligned new first-publication timestamps with the configured CMS timezone.
  • Improved News Sitemap readiness handling after upgrades and database restores.
  • Added accessible public login feedback.
  • Reduced theme startup flashes and discovery-footer flicker.
  • Improved Posts/Pages tablet actions and long IPv6 address wrapping.
  • Added compact TechPress mobile Latest Updates rows with 16:9 thumbnails.
  • Improved Digest footer contrast.
  • Updated compatible dependencies and strengthened SEO regression coverage.

Upgrade Notes

  1. Back up the database, uploads and private configuration.
  2. Apply the complete Deploy package.
  3. As Primary Admin, run Database Repair to create personal-key storage and its private lock anchor.
  4. Run System Tools > Repair `.htaccess` once to refresh managed routing rules.

Keep data/credential_master.key.php backed up privately, including after encryption rotation. Restore the matching key material alongside encrypted credentials.

A files-only rollback to older code ignores personal keys and may resume shared paid-key access. Review that access before rolling back.

PHP 8.2 remains the minimum; PHP 8.3+ is recommended.

Packages

  • Deploy ZIP: Ready-to-upload production files.
  • Source ZIP: Source code, development tooling and maintained tests.
