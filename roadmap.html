VonCMS Roadmap

v1.28.0: Editorial planning

Released. v1.28.0 is available in the published BluePrint release.

The first BluePrint release brings the day's editorial work into clearer view.

  • Grouped navigation and quick actions. Organize admin destinations by purpose, with role-aware actions for creating content and events.
  • Editorial Calendar. Review publication dates and authors alongside internal events, meetings, and agenda entries in month and list views. Viewing the calendar does not change an article's publication schedule.
  • VonAnalytics measurement choices. Keep Strict as the default and offer an optional Balanced, browser-based mode. Reports distinguish the measurement methods; browser counts are not verified people.
  • Shared AI credential protection. Encrypted owner Gemini key storage, masked Settings responses, and owner-only encryption-key rotation. This is separate from the planned personal staff key feature.

Existing sites need Primary Admin Schema Repair for Calendar and Balanced analytics storage. Review the upgrade guidance before updating.

v1.28.1: Publishing tools and reliability

Released. The published v1.28.1 update adds optional tools and targeted corrections without a new database table or required migration from v1.28.0.

  • Opt-in Hybrid analytics. Collect Strict and Balanced measurements independently, with separate reports. Existing settings and history stay intact; only the Primary Admin can change collection.
  • Post/Page deletion previews. Review records before single or bulk permanent deletion. Cancellation sends no delete request, and partial failures retain unconfirmed items for review. This is not Trash, Restore, or Undo.
  • Optional News Sitemap. Publish a feed of eligible news articles from the preceding 48 hours, with publication, language, and category controls. It supplements the ordinary sitemap and does not guarantee Google News inclusion.
  • Reliability and access corrections. Refined protected Post reads, delegated permissions, native measurement filtering, public read requests, Related Posts handling, and Dashboard presentation.

Hybrid and News Sitemap require explicit configuration. Read the upgrade guidance; earlier Calendar and analytics storage prerequisites still apply.

v1.28.2: Leaner public settings

Planned. Send public pages only the configuration their active theme and features need.

Keep inactive theme settings saved for later without sending them to every visitor. This work targets smaller settings payloads while preserving disabled features and existing site behavior.

v1.28.3: Your personal AI key

Planned. Let eligible staff save a personal AI key in their own account profile, building on the existing editor key entry.

The scope is personal credential storage and explicit key selection for supported AI tools. It does not add new providers, image generation, or AI access for ordinary members.

v1.28.4: Staff activity log

Planned. Help the site owner review important staff actions, with the actor, target, time, and recorded outcome.

Build on existing event records with scoped access, filters, and bounded history. The log is for supported staff operations, not every click or keystroke, and it is not a restorable article revision.

v1.28.5: Interface languages

Planned. Introduce interface translation gradually, with English as the source language and Malay as the first complete language pack.

Establish missing-text fallbacks and right-to-left layout foundations before wider language coverage. Translating the interface does not automatically translate articles or create multilingual URLs.

Unassigned: Trash and restore

Planned, version not assigned. Give deleted posts and pages a recovery step before permanent removal. The confirmation preview in v1.28.1 is not a recovery feature.

Move content to Trash, restore it as a draft, or explicitly delete it permanently. Restoring an item is intended to keep it off the public site until an authorized publisher chooses to publish it again.

One release at a time.

Each feature has its own verification before release. Later planned work does not have to be finished for an earlier, verified slice to ship. The v1.28.6 and later slots are reserved for maintenance, compatibility, security, and confirmed regression fixes.

Looking for features you can use now? Read the published release notes or check the current documentation. Roadmap entries are not download availability.
